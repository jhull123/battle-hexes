# 01 - No Op Scripted Player

This is the implementation spec to create the starter implementation for the scripted objective
player that is described in https://github.com/jhull123/battle-hexes/issues/407.

This first spec is a thin slice that creates a new scripted objective player that is selectable in
the player types menu for all scenarios. The initial implementation will be "no op", meaning that
the player makes no moves. This is a base that we will build on in later specs to add more
functionality incrementally.
